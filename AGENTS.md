# Project conventions

- Use English for README files, documentation, code, comments, tests, and CLI messages.
- Use Angular-style commit messages: `type(scope): subject`, with an imperative subject and no trailing period.
- Keep the CLI small. The repository supplies available skills; users choose skills and Agent tools locally.
- Show planned removals before confirmation. Preserve unmanaged files and refuse to overwrite local edits.
- Use https://github.com/boltguo/skillsm as the project repository URL.
- Run `npm run check` and `npm test` after behavior changes.
